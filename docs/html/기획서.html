#포켓몬 키우기 기획서

이 문서는 2026-11-05에 이미 구현·배포된 코드(dev 브랜치, v1.1.0 내용), README, ROADMAP, DEVLOG, git 히스토리, 개발 글(dev-post/04-pokemon-idle/post.md)을 보고 거꾸로 정리했다. 구현된 기능을 사용자가 요구한 기능으로 본다.

관련 문서: 설계서 · 구현도 · 결정기록

#한 줄 소개

바탕화면 위에 항상 떠 있는 도트 포켓몬을 키우는 생산성 앱. 집중 타이머를 켜면 포켓몬이 잠들고, 끝나면 깨어나 포인트를 받아 자란다. 야생 배틀·포획·보관함까지 있다.

#왜 만들었나

  • 데스크톱 한쪽 구석에 포켓몬이 살고 있으면 재밌겠다는 생각에서 시작했다(개발 글).
  • 포켓몬을 키우는 게 목적이 아니라, 집중하는 시간에 같이 자라는 펫을 원했다(개발 글).
  • "포켓몬인데 배틀이 없으면 섭하다"는 이유로 배틀·포획·보관함까지 넓혔다(개발 글).

#누가 쓰나

  • 집중 타이머(포모도로)를 쓰며 일하거나 공부하는 사람.
  • 포켓몬을 해 본 사람. 이름·기술·공식이 본가와 어긋나면 바로 티가 나므로 공식 데이터에 맞춘다.
  • macOS·Windows 사용자. 설치 파일 하나로 쓰거나 소스로 직접 빌드한다.

#목표 (개발 글의 네 가지 기준)

  1. 집중하는 시간에 같이 자라는 펫일 것
  2. 포켓몬 해 본 사람이 봐도 어색하지 않을 것
  3. 일하는 중에 방해가 되지 않을 것
  4. 혼자서도 계속 굴러갈 것

#핵심 시나리오

  1. 첫 실행: 패널 창만 뜬다 → 스타터 3종(이상해씨·파이리·꼬부기) 중 하나를 고른다 → 작은 펫 창이 나타나 화면을 돌아다닌다.
  2. 집중: 집중 시간(1~120분, 기본 25분)을 정하고 시작 → 펫이 잠든다 → 1분마다 +2pt, 끝나면 +75pt 보너스 → 레벨업, 조건이 되면 3초 진화 연출.
  3. 배틀: 배틀 탭에서 야생 포켓몬과 조우(-10pt) → 기술을 골라 턴제 배틀 → 이기면 레벨 비례 포인트, HP가 낮아지면 몬스터볼로 포획 → 보관함으로.
  4. 관리: 상점에서 비타민·TM·볼·진화의 돌·지니기 아이템 구매 → 스탯 탭에서 기술 교체, EV 확인 → 포켓몬센터에서 HP·PP 회복(-20pt) → 보관함에서 파트너 교체.
  5. 업데이트(1.1.0~): 앱이 새 버전을 미리 받아 두면 트레이 메뉴에 "새 버전 설치하고 다시 시작"이 생긴다. 누를 때만 설치되므로 집중 중에 꺼지지 않는다.

#기능 목록

#구현됨

펫

  • 투명·항상 위 펫 창(100~160px, 진화 단계별), 화면 배회, 드래그 이동(멀티 모니터)
  • 상태: idle · happy(포인트 획득 2초) · sleeping(집중 중) · evolving(진화 3초)
  • 도트 19종(평소·잠잘 때 두 벌), 도트가 없는 종은 PokeAPI 스프라이트

집중모드

  • 1~120분 타이머, 시계 기준(Date.now()) 계산
  • 분당 +2pt, 완료 +75pt, 중단하면 경과 시간만큼 지급

성장

  • 레벨 n 누적 포인트 = n² × 4, 3단 진화(스타터 3라인), 피카츄 → 라이츄(천둥의돌)
  • 성격·특성·개체값(IV 0~31)·노력치(EV, 비타민 +10, 스탯당 252·합계 510)
  • 7세대(울트라썬·울트라문) 레벨업 기술, 슬롯 4개, TM 학습
  • 진화해도 닉네임·성격·특성·IV·기술·EV 유지

배틀

  • 야생 조우(레벨 기반 풀), 스피드 선공, 턴을 0.5초 장면으로 나눠 표시
  • 18타입 상성, 물리·특수·변화, 명중률, 상태이상 5종, 능력치 단계 ±6, 날씨(쾌청·비 5턴), 고정 데미지(용의분노·나이트헤드)
  • 포켓몬센터 회복

포획·보관함

  • 몬스터볼(30pt ×1.0)·슈퍼볼(80pt ×1.5)·하이퍼볼(150pt ×2.0), HP·상태이상·종별 포획률 반영, 볼 흔들림 연출
  • 보관함: 목록, 파트너 교체, 닉네임 변경, 놓아주기

상점

  • 진화의 돌, 지니기 아이템 10종(장착·표시만), 비타민 6종, TM 30종 이상

앱

  • 패널 탭: 홈 · 샵 · 스탯 · 보관함 · 배틀 · 센터 · 설정
  • 설정: 데이터 초기화
  • 트레이 아이콘·메뉴
  • 1.0.0(Electron) 저장 데이터를 첫 실행 때 자동으로 가져오기
  • 자동 업데이트(1.1.0~)

#나중 (근거가 있는 것만)

  • 지니기 아이템의 배틀 효과: README에 "배틀 중 효과는 아직 구현 전"이라고 적혀 있다.
  • 성격 데이터 공식 검증: 개발 글에 "검증 대상이 기술이랑 도구 이름뿐이라 성격 데이터는 아직 확인을 못 했다"고 적혀 있다.
  • 정답 이름 목록(.claude/approved-pokemon-names.json) 재점검: 개발 글에 마지막 정정이 반영 안 돼 틀린 이름이 정답으로 들어간 적이 있다고 적혀 있다.

#범위 밖

항목 이유
화면 위에 따로 뜨는 배틀 창(풀숲 오버레이) 일하는 중에 창이 불쑥 뜨면 방해된다. 배틀은 패널 탭으로만(ROADMAP Phase 3, 개발 글)
집중 아닌 때의 자동 수면(30분 무입력) 잠든 모습이 "지금 집중 중"이라는 신호가 되게 하려고 뺐다(개발 글)
휴식(break) 타이머 집중 타이머만 남겼다(9119059)
9세대 기술 목록 레벨 15 이후 배울 기술이 거의 없어 키우는 재미가 없다(개발 글)
상업적 이용 비상업 팬 프로젝트. 포켓몬 명칭·도트·기술명의 권리는 Nintendo / Game Freak / The Pokémon Company에 있다(개발 글 공지)
Linux 빌드 대상이 macOS·Windows뿐이다

#지원 플랫폼과 배포 채널

  • macOS 11 이상(universal dmg), Windows 10/11(NSIS 설치 파일)
  • GitHub Releases(공개 저장소 ESeungJun/poketmon_idle). 2026-11-05 기준 공개된 릴리스는 v1.0.0이고, v1.1.0은 태그와 릴리스 워크플로가 대기 중이다(gh run list).
  • 소스 빌드: npm install && npm run build(Node 18+, Rust)

#완료·성공 기준

  • 하루 50분 집중 기준 1차 진화(Lv.16)까지 약 4일, 2차 진화(Lv.32)까지 약 16일(7f8f9e3 커밋 계산).
  • 포켓몬 이름·기술·도구 이름이 PokeAPI 공식 한국어 이름과 같다(pokemon-expert 에이전트, /verify-pokemon-ko 스킬로 검증).
  • 펫 창은 집중을 방해하지 않는다: 배틀 창이 따로 뜨지 않고, 업데이트는 사용자가 누를 때만 설치된다.
  • 진화·종 교체 뒤에도 스탯·기술이 유지된다.

참고 수치(개발 글, Phase 5 완료 시점): 2026-03-05 첫 커밋 → 03-23 Phase 5 완료, PR 44개, 도트 19종, 배틀 엔진 792줄, 상태 관리 721줄. Tauri 전환 후 설치 파일 크기 macOS 198MB → 4MB, Windows 92MB → 1.4MB(ROADMAP).
