#포켓몬 키우기 결정기록

이 기록은 2026-11-05에 git 히스토리·개발 글에서 복원했다. 근거는 커밋 해시, 개발 글(~/Desktop/claudeProject/dev-post/04-pokemon-idle/post.md, 이하 "개발 글"), ROADMAP, DEVLOG다. 결정은 모두 이승준이 했다.

관련 문서: 기획서 · 설계서 · 구현도

#2026-03-05 Electron + React로 데스크톱 펫 시작

  • 무엇을 정했나: Electron 메인 프로세스 + React 화면, 펫 창과 패널 창 두 개.
  • 후보: 기록 없음.
  • 고른 이유: 기록 없음.
  • 누가 정했나: 이승준.
  • 버린 시도: 없음. 2026-11-04에 Tauri로 옮겼다(아래).
  • 근거: 7fb49ad.

#2026-03-05 빌드한 macOS 앱이 켜자마자 죽는 문제는 후처리 스크립트로

  • 무엇을 정했나: electron-builder가 Electron 바이너리를 건드려 SIGTRAP으로 죽었다. 빌드 뒤 원본 바이너리로 앱 번들을 다시 감싸는 postbuild 스크립트를 둔다.
  • 후보: 기록 없음.
  • 고른 이유: 개발 모드에서는 멀쩡해서 빌드한 앱을 직접 켜 보기 전엔 몰랐다(개발 글).
  • 누가 정했나: 이승준.
  • 버린 시도: 그대로 패키징.
  • 근거: 0ce97da. Tauri 전환 뒤에는 쓰지 않는다.

#2026-03-06 첫 화면은 패널만, 스타터는 3종

  • 무엇을 정했나: 첫 실행엔 패널만 띄우고, 스타터를 고른 뒤 펫 창이 나온다. 스타터를 이상해씨·파이리·꼬부기로 바꾸고 팬텀(겐가르)을 뺀다.
  • 후보: 기존 스타터 구성 / 1세대 스타터 3종.
  • 고른 이유: 처음 고르는 순간이 단순하도록(개발 글 결정표).
  • 누가 정했나: 이승준.
  • 버린 시도: 팬텀이 있던 스타터 구성, 첫 실행부터 펫 창 표시.
  • 근거: 0a7d5a4, d48fab6, ROADMAP Phase 1.

#2026-03-06 잠은 집중할 때만, 휴식 타이머는 뺀다

  • 무엇을 정했나: 펫은 집중모드에서만 잔다. 30분 무입력 자동 수면과 휴식(break) 타이머를 없애고, 집중 시간을 1~120분으로 고를 수 있게 한다.
  • 후보: 무입력 자동 수면 유지 / 집중 전용 수면.
  • 고른 이유: 자는 모습이 곧 "지금 집중 중"이라는 신호가 되게(개발 글).
  • 누가 정했나: 이승준(개발 글 "1. 이 앱은 집중이 먼저다").
  • 버린 시도: 무입력 자동 수면, 휴식 타이머.
  • 근거: 94fa323(#2), 9119059(#15).

#2026-03-06 브랜치 전략을 훅으로 강제

  • 무엇을 정했나: master·dev 직접 push를 hooks/pre-push로 막고, feature/* → dev PR로만 넣는다.
  • 후보: 기록 없음.
  • 고른 이유: AI가 실수로 master에 바로 올리지 않게(개발 글 결정표).
  • 누가 정했나: 이승준.
  • 버린 시도: 규칙만 문서로 두기.
  • 근거: 5a84a46.

#2026-03-06 IPC 보안: 저장소 키 허용 목록과 리스너 해제

  • 무엇을 정했나: sendSync를 없애고, 저장소 키 허용 목록을 두고, IPC 리스너는 해제 함수를 돌려준다.
  • 후보: 기록 없음.
  • 고른 이유: 기록 없음.
  • 누가 정했나: 이승준.
  • 버린 시도: sendSync, 아무 키나 쓰는 저장소.
  • 근거: e5baa17, 20513b7. Tauri 전환 뒤에도 ALLOWED_STORE_KEYS로 유지.

#2026-03-06 포켓몬 이름은 AI 기억이 아니라 공식 데이터로

  • 무엇을 정했나: 이름·기술·도구는 PokeAPI 공식 한국어 이름(ko)과 맞춘다. pokemon-expert 에이전트, /verify-pokemon-ko 스킬, CLAUDE.md 규칙("직역·영어 음차·일본어 음차 금지")을 둔다.
  • 후보: AI가 쓴 이름 그대로 / 공식 데이터 검증.
  • 고른 이유: AI가 쓴 이름이 40건 넘게 틀렸다(보디슬램 → 누르기, 겐가르 → 팬텀, 잠자기가루 → 수면가루 등). 포켓몬 해 본 사람은 바로 알아챈다(개발 글).
  • 누가 정했나: 이승준(개발 글, 목표 "포켓몬다움").
  • 버린 시도: AI 기억으로 채운 데이터. 처음 정정 14건, 전수 검사로 5건 추가.
  • 근거: 1e45296(#12), 8fa0b00(#13), 6167ce1(#10 에이전트).

#2026-03-06 기술 목록은 7세대(울트라썬·울트라문) 기준

  • 무엇을 정했나: 스타터 계열 9종의 레벨업 기술을 USUM 기준으로 바꾸고 "배울 기술" UI를 뺀다.
  • 후보: 9세대 / 7세대.
  • 고른 이유: 9세대 기준이면 레벨 15 이후 배울 기술이 거의 없어 키우는 재미가 없다. 7세대가 포켓몬당 평균 7~10개 많다(fe38ab3, 개발 글).
  • 누가 정했나: 이승준.
  • 버린 시도: 9세대 기술 목록.
  • 근거: fe38ab3(#16).

#2026-03-06 포인트를 약 1.5배 올린다

  • 무엇을 정했나: 집중 분당 1 → 2pt, 집중 완료 50 → 75pt(당시 할일 완료 20 → 30pt).
  • 후보: 처음 값 유지 / 상향.
  • 고른 이유: 처음 값으로는 진화까지 너무 오래 걸렸다. 하루 50분 집중으로 1차 진화 약 4일, 2차 약 16일이 되게(7f8f9e3, 개발 글).
  • 누가 정했나: 이승준.
  • 버린 시도: 처음 포인트 값.
  • 근거: 7f8f9e3(#17).

#2026-03-07 도트 파일은 도감 번호로, 진화해도 스탯 유지

  • 무엇을 정했나: *-anims.js를 도감 번호로 이름 짓고, 3단계는 32열 그리드로 다시 변환한다. 외곽선 색을 #191919로 통일한다. 진화는 speciesId만 바꾸고 성격·특성·개체값·기술을 그대로 둔다.
  • 후보: 기록 없음.
  • 고른 이유: 진화하면 petStats를 초기화하던 버그를 고치려고.
  • 누가 정했나: 이승준.
  • 버린 시도: 영문 이름 파일, 진화 시 스탯 초기화.
  • 근거: 8ec17ad(#18).

#2026-03-12 배틀은 별도 창 없이 패널 탭으로

  • 무엇을 정했나: 화면에 풀숲 창을 띄우는 대신 패널 안 배틀 탭에서 하고 싶을 때 한다.
  • 후보: 별도 오버레이 창 / 패널 탭.
  • 고른 이유: 일하는 중에 화면 위로 창이 불쑥 뜨면 방해된다(개발 글).
  • 누가 정했나: 이승준(개발 글 "1. 이 앱은 집중이 먼저다").
  • 버린 시도: 별도 오버레이 창.
  • 근거: ROADMAP Phase 3 "아키텍처 확정", 16d97d7.

#2026-03-12 배틀 로그는 장면으로 나눠 0.5초씩, 능력치 단계 구현

  • 무엇을 정했나: processTurn()이 장면 배열을 돌려주고 화면이 0.5초씩 재생한다. 스피드로 선공을 정하고 능력치 단계(±6)를 본가 배율로 구현한다. 포켓몬센터 탭을 추가한다.
  • 후보: 한 번에 결과 표시 / 장면 재생.
  • 고른 이유: 내 공격과 상대 공격 로그가 한꺼번에 찍혀 누가 먼저 했는지 몰랐다. 울음소리·꼬리흔들기가 전부 "효과가 없는 것 같다"로만 나왔다(개발 글, DEVLOG).
  • 누가 정했나: 이승준.
  • 버린 시도: 한 번에 찍는 로그, 변화 기술 무효 처리.
  • 근거: 20fbafd, DEVLOG Phase 3.

#2026-03-12 잠자는 도트는 AI로 만들고 손으로 다듬는다

  • 무엇을 정했나: 평소 모습은 공식 도트를 바탕으로, 공식에 없는 잠자는 모습은 AI로 만든 뒤 튀는 픽셀·색을 미리보기 서버에서 한 칸씩 고친다.
  • 후보: 기록 없음.
  • 고른 이유: 공식 도트에는 잠자는 모습이 없다(개발 글).
  • 누가 정했나: 이승준.
  • 버린 시도: 없음.
  • 근거: eacfde0, 98ea3f8, 8fa52aa, 개발 글 "3. 도트도 공식 모습에 맞추기".

#2026-03-23 데미지·보상·포획 공식을 본가에 가깝게

  • 무엇을 정했나: 데미지에 레벨을 반영하고, 배틀 보상을 고정 30pt에서 10 + 레벨×1.5로, 포획을 종별 포획률·HP·볼·상태이상 보정의 본가 기반 공식으로 바꾼다.
  • 후보: 단순 공식(위력 × 공/방 × 상성 × 0.5, 고정 보상) / 본가 기반.
  • 고른 이유: 기록 없음(Phase 5 밸런스 조정).
  • 누가 정했나: 이승준.
  • 버린 시도: Phase 3의 단순 데미지 공식, 고정 보상.
  • 근거: 0bf74ca, ROADMAP 3-3.

#2026-05-28 macOS 소스 빌드는 dmg 대신 .app 직접 실행

  • 무엇을 정했나: 빌드 후 dmg를 만드는 단계를 빼고 빌드된 .app을 그대로 쓴다. 다른 Mac으로 옮기지 말고 그 Mac에서 빌드하라고 안내한다.
  • 후보: 임시 서명 dmg 배포 / .app 직접 실행.
  • 고른 이유: 다른 Mac에서 Gatekeeper가 임시 서명 dmg를 거부했다.
  • 누가 정했나: 이승준.
  • 버린 시도: create-dmg.js(fb1e195에서 추가).
  • 근거: 0a43631.

#2026-10-22 서명·공증된 설치 파일로 첫 공개 릴리스

  • 무엇을 정했나: v* 태그로 Developer ID 서명 + Apple 공증 universal dmg와 Windows NSIS를 draft 릴리스로 만든다. macOS는 dmg로만 배포한다.
  • 후보: dmg + zip / dmg만.
  • 고른 이유: zip은 한글 헬퍼 이름 때문에 서명이 깨졌다(b176289).
  • 누가 정했나: 이승준.
  • 버린 시도: zip 배포, 소스 빌드만 안내.
  • 근거: 2712832, b176289, v1.0.0.

#2026-11-04 Electron에서 Tauri로 옮긴다

  • 무엇을 정했나: 메인 프로세스를 src-tauri/src/lib.rs로 옮긴다. 화면 코드는 그대로 두고 src/platform/tauri.js가 window.electronAPI를 같은 모양으로 만든다. 저장소는 같은 config.json 형식이고 첫 실행 때 Electron 데이터를 가져온다.
  • 후보: Electron 유지 / Tauri.
  • 고른 이유: 설치 파일이 macOS 198MB → 4MB, Windows 92MB → 1.4MB(ROADMAP). 화면 코드를 건드리지 않고 옮길 수 있게 IPC 모양을 유지했다.
  • 누가 정했나: 이승준.
  • 버린 시도: Electron(1.0.0까지).
  • 근거: 782fc19, 957bc24, 576aaae, 릴리스 700e42e(v1.1.0).

#2026-11-04 자동 업데이트는 미리 받고 누를 때만 설치

  • 무엇을 정했나: 켠 뒤 15초, 이후 6시간마다 latest.json을 확인해 미리 받아 두고, 트레이 메뉴의 "새 버전 설치하고 다시 시작"을 누를 때만 설치한다. 실패하면 메뉴를 되돌린다.
  • 후보: 기록 없음.
  • 고른 이유: 집중 타이머 도중에 앱이 꺼지지 않게(README).
  • 누가 정했나: 이승준.
  • 버린 시도: 없음(1.0.0엔 업데이트 기능이 없었다).
  • 근거: b79c070, 1925cdf.
