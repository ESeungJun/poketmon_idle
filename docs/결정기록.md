## 2026-03-06 첫 화면은 패널만, 스타터는 3종

- **무엇을 정했나**: 첫 실행엔 패널만 띄우고, 스타터를 고른 뒤 펫 창이 나온다. 스타터를 이상해씨·파이리·꼬부기로 바꾸고 팬텀(겐가르)을 뺀다.
- **후보**: 기존 스타터 구성 / 1세대 스타터 3종.
- **고른 이유**: 처음 고르는 순간이 단순하도록(개발 글 결정표).
- **누가 정했나**: 이승준.
- **버린 시도**: 팬텀이 있던 스타터 구성, 첫 실행부터 펫 창 표시.
- **근거**: `0a7d5a4`, `d48fab6`, ROADMAP Phase 1.

## 2026-03-06 잠은 집중할 때만, 휴식 타이머는 뺀다

- **무엇을 정했나**: 펫은 집중모드에서만 잔다. 30분 무입력 자동 수면과 휴식(break) 타이머를 없애고, 집중 시간을 1~120분으로 고를 수 있게 한다.
- **후보**: 무입력 자동 수면 유지 / 집중 전용 수면.
- **고른 이유**: 자는 모습이 곧 "지금 집중 중"이라는 신호가 되게(개발 글).
- **누가 정했나**: 이승준(개발 글 "1. 이 앱은 집중이 먼저다").
- **버린 시도**: 무입력 자동 수면, 휴식 타이머.
- **근거**: `94fa323`(#2), `9119059`(#15).

## 2026-03-06 포켓몬 이름은 AI 기억이 아니라 공식 데이터로

- **무엇을 정했나**: 이름·기술·도구는 PokeAPI 공식 한국어 이름(`ko`)과 맞춘다. `pokemon-expert` 에이전트, `/verify-pokemon-ko` 스킬, CLAUDE.md 규칙("직역·영어 음차·일본어 음차 금지")을 둔다.
- **후보**: AI가 쓴 이름 그대로 / 공식 데이터 검증.
- **고른 이유**: AI가 쓴 이름이 40건 넘게 틀렸다(보디슬램 → 누르기, 겐가르 → 팬텀, 잠자기가루 → 수면가루 등). 포켓몬 해 본 사람은 바로 알아챈다(개발 글).
- **누가 정했나**: 이승준(개발 글, 목표 "포켓몬다움").
- **버린 시도**: AI 기억으로 채운 데이터. 처음 정정 14건, 전수 검사로 5건 추가.
- **근거**: `1e45296`(#12), `8fa0b00`(#13), `6167ce1`(#10 에이전트).

## 2026-03-12 배틀 로그는 장면으로 나눠 0.5초씩, 능력치 단계 구현

- **고른 이유**: 내 공격과 상대 공격 로그가 한꺼번에 찍혀 누가 먼저 했는지 몰랐다. 울음소리·꼬리흔들기가 전부 "효과가 없는 것 같다"로만 나왔다(개발 글, DEVLOG).

- **버린 시도**: 한 번에 찍는 로그, 변화 기술 무효 처리.

## 2026-11-04 Electron에서 Tauri로 옮긴다

- **무엇을 정했나**: 메인 프로세스를 `src-tauri/src/lib.rs`로 옮긴다. 화면 코드는 그대로 두고 `src/platform/tauri.js`가 `window.electronAPI`를 같은 모양으로 만든다. 저장소는 같은 `config.json` 형식이고 첫 실행 때 Electron 데이터를 가져온다.
- **후보**: Electron 유지 / Tauri.
- **고른 이유**: 설치 파일이 macOS 198MB → 4MB, Windows 92MB → 1.4MB(ROADMAP). 화면 코드를 건드리지 않고 옮길 수 있게 IPC 모양을 유지했다.
- **누가 정했나**: 이승준.
- **버린 시도**: Electron(1.0.0까지).
- **근거**: `782fc19`, `957bc24`, `576aaae`, 릴리스 `700e42e`(v1.1.0).
